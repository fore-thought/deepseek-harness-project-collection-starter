## 2. 工程规范

- 文档格式：UTF-8（无 BOM）、Markdown、LF 换行（见 AGENTS.md §4）
- 文件名：小写字母 + 连字符，不用空格和中文文件名
- 结论分层：数字/阈值/事实性结论必标 [MEASURED]/[ESTIMATED]/[UNKNOWN]
  （见 AGENTS.md §2.4）
- 禁止本地绝对路径：文档/脚本中不出现用户本地绝对路径（如 `C:\...`），
  一律项目相对路径或中性描述（见 AGENTS.md §4）
- **敏感信息管理**：
  - 真实凭证（API Key/令牌/密码）放项目**根级** `configs/.env`
    （gitignore 掉），同时保留 `configs/.env.template` 占位符版（可进 git）；
  - gitignore 至少排除：`*.env`、`secrets/`、`credentials/`、`*.pem`、`*token*`、
    `configs/project-config.toml`（项目配置，含远端 URL 等**非密钥**项，不入库；密钥见 `.env`）；
  - 其中 `secrets/`、`credentials/`、`*.pem`、`*token*` 是**故意用裸名的例外**（与 AGENTS.md §4
    「精确路径、不用裸名」的写法意见并存，见下方说明）：宁可误伤任意深度的同名普通文件
    （如 `tokenizer.json`、`tokens/`），也不放过密钥；被误伤时改名或 `git add -f`，
    **不要为此收窄模式**——收窄即缩小防泄露覆盖面。两份 `.gitignore` 的注释同此口径。
  - 组级 `user-config.toml` 放 `shared-standards/`（.gitignore 排除，不入库）；
  - 模板命名统一为「实例名 + `.template`」（`project-config.toml.template` /
    `user-config.toml.template` / `.env.template`），占位符版可入库
    （实例 = 去掉 `.template` 后缀，本地填写）；
  - 权限分级：运行所需令牌代理可见；支付/主账号类仅用户可见——**代理不得把它们转写进
    任何文档、总结、日志或交接文件**，只在会话内按需使用（用户 2026-10-08 决定：主屏障
    是 ignore 防提交＋不转写；该文件在工作区内、代理可读，这一点已知并接受）；
  - 泄露应急：发现泄露 → 立即撤销/轮换 → 记 decisions → 复盘原因。
- **政策监控清单**：平台规则/口径变动统一登记在一份清单（每平台一行：
  公告渠道 + 最近核实日期 + 最近变动 + 影响面[指标字典?/合规?]）；
  指标字典与合规核实**共用此清单**，不各自维护两套。清单位置各项目自定
  （建议 `process/docs/` 或目标书附录）；渠道来源 = 平台官方公告。
