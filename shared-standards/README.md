# shared-standards（项目组级公共规范）

> 本文件夹 = 项目组内所有项目共享的规范与定制，位于各项目工作区之外，
> 被各项目以**只读**方式引用。**不随项目复制**（项目模板只复制 project-template）。

## 内容

- `AGENTS.md`：项目组协作规范——TOP 规则、四道闸门禁、通用工作规则、项目组特色定制
- `standards.md`：全局合规与工程规范、项目组特色约定

## 引用方式（项目侧）

- 项目工作区的 `AGENTS.md` 第 0 节声明依赖：`../shared-standards/AGENTS.md`
- 新项目 = 把 `../project-template/` 复制到本文件夹同级（project-group 下）并改名，
  以**独立工作区**在 DSH 打开；相对路径自动成立，无需修改引用。

## 更新规则

- 本文件夹对各项目工作区**只读**：项目代理不能直接写入（工作区写权限不覆盖此处）。
- 需要更新时走**提权通道**：对越界写操作申请一次性权限并说明理由，经用户批准后执行；
  日常引用一律只读，不把项目合并进同一工作区。
