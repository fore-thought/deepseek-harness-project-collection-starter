# shared-standards（项目组级公共规范）

> 本文件夹 = 项目组内所有项目共享的规范与定制，位于各项目工作区之外，
> 被各项目以**只读**方式引用。**不随项目复制**（项目模板只复制 project-template）。
> 版本: v1.11 ｜ 最近修订: 2026-09-16 ｜ 变更记录见文末。

## 内容

- `AGENTS.md`：项目组协作规范——TOP 规则、四道闸（+调研阶段 §7.6、结项闸 §7.7）、
  通用工作规则、必读文档读取方式、项目级 AGENTS.md 体量与指针化、并行前提、
  项目组特色定制、规约修订流程（§9 D1）
- `pipeline-and-roles.md`：**多角色流水线（可选能力）**——三个角色与写权表、单元文件夹
  传送带、归属与越界规程、四层降级、并行纪律、接续顺序。**启用多角色时读，单会话项目不必读**
- `standards.md`：全局合规与工程规范（横向）、敏感信息管理、政策监控清单
- `user-config.toml.template`：组级用户配置模板（实例 `user-config.toml` 本地填写，
  `.gitignore` 排除不入库）。命名规则：模板名 = 实例名 + `.template`

> **本文件夹不受 DSH 会话指令注入限制**：它在项目根之外，会话开局不会注入，
> 由项目级 `AGENTS.md` 指向、由代理按需读取（组级 AGENTS.md §6）。

## 引用方式（项目侧）

- 项目工作区的 `AGENTS.md` 第 0 节声明依赖：`../shared-standards/AGENTS.md`
- 新项目 = 把 `../project-template/` 复制到本文件夹同级（project-group 下）并改名，
  以**独立工作区**在 DSH 打开；相对路径自动成立，无需修改引用。

## 更新规则

- 本文件夹对各项目工作区**只读**：项目代理不能直接写入（工作区写权限不覆盖此处）。
- 需要更新时走**提权通道**：对越界写操作申请一次性权限并说明理由，经用户批准后执行；
  日常引用一律只读，不把项目合并进同一工作区。
- 修订流程见 `AGENTS.md` §9（提案→批准→实施→版本化→变更记录）。
- 版本化：每个文件头部带版本号 + 文末变更记录表；含示例的条款，格式变更必须同步更新示例。
