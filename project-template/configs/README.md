> **本地环境区**（项目根）：本机环境与配置，**不进仓库**——实例文件被 `.gitignore` 排除。
> 两份配置：`project-config.toml`（非密钥）+ `.env`（密钥，只存于此）；模板同名加 `.template`，
> 去掉后缀即实例名。
> 谁做什么：判定与引导＝制作人；复制＝制作人经用户同意代建，或用户自建；**值一律由用户填**。
> 什么时候需要：第一次 git 远端操作 / 第一次真的要访问某平台 / 第一次从不同系统入口打开 /
> 第一次 commit（git 身份）——四个时刻各触发一次，不做开局体检（详见组级 AGENTS.md §6）。
> 凭证分级：密钥只放 `.env`；代理**不得把它们转写进任何文档、总结、日志或交接文件**
> （组级 standards.md §2）。
