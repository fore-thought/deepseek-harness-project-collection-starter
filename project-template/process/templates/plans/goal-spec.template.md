# 目标定义书（goal-spec 模板）

> 模板位置：本文件是**模板**，永不改内容；**实例** = 复制为 `process/docs/plans/goal-spec.md`
> （去掉 `.template` 后缀）后填写。
> 用途：立项闸产物（项目组级规范 ../../../../shared-standards/AGENTS.md §7.1）。
> **6 字段全部填写并经用户签名后，才可进入规划。**
> 填写要求：全部用具体描述；禁止"高质量""效果好"等无法验收的形容词。
> 字段可以"**原则级 + [VERIFY] 占位**"签署（方向承诺与细节充实解耦，细节由调研阶段回填）。

| 字段 | 内容 |
|---|---|
| `成品形态` | 一句话 + 一段让没参与的人能看懂最终成品长什么样的描述 |
| `质量上限` | 标杆是谁（贴具体链接/图） |
| `质量下限` | 什么样的结果不可接受（具体到画面/时长/观感等） |
| `渠道与受众` | 发布渠道 + 目标受众 |
| `成功判定` | 3 条事后能打勾的指标 |
| `排除项` | 明确不做的事 |

## 签名

- [ ] 用户确认通过（提问卡片逐字段确认）
- 签名日期：`<YYYY-MM-DD>`
