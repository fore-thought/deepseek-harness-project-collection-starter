# 真机实测记录（measurements 模板）

> 模板位置：本文件是**模板**，永不改内容；**实例** = 复制为 `process/docs/measurements.md`
> （去掉 `.template` 后缀）后填写。
> 本文件记录真机/真环境的**实测数据**，用于校准 `process/docs/assumptions.md` 中的纸面估算。
> 只有写入本文件的数字才是 [MEASURED] 级结论。
> 可选做法（项目自行决定是否落地）：成本类合计不必读全文，可写一个
> `process/project/scripts/` 下的合计脚本，只输出「当前累计 / 预算总额 / 剩余额度」三个数，
> 原始流水仍留在本文件供追溯。
> **写者**：制作人独占（多角色模式）；单会话模式下由该会话写。

## 记录格式

```
### M-XXX｜日期｜验证的假设 ID（如 ASSUMPTION-001）

- 环境：硬件 / 软件版本 / 依赖 / 模型权重
- 命令或复现步骤：简述（可指向 process/project/scripts/ 下的脚本路径）
- 结果：数值 + 单位（耗时、资源峰值、成本等）
- 对照：假设值 vs 实测值，偏差原因
- 备注：[MEASURED] 结论、异常、可复现性
```
