# 决策记录（Decision Records 模板）

> ADR 风格：记录关键工程/方向决策的**背景、选项、选择与理由**，供后续会话回溯。
> 每个决策独立编号，新决策追加在末尾。

## 决策索引

| ID | 日期 | 决策 | 状态 |
|---|---|---|---|
| DECISION-001 | `<日期>` | `<一句话>` | ✅ 已批准 |

## 记录格式

```
### DECISION-XXX｜日期

- 背景：为什么需要决策（关联假设 ID [ASSUMPTION-XXX]）
- 选项：A / B / C（各一句）
- 决策：选哪个，为什么
- 代价/风险：放弃的选项与后续注意
- 影响：哪些计划/文件/假设被改变
```
