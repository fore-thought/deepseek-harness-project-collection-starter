# 会话交接（HANDOFF）

> 本文件有两种形态，**开头一行写明当前是哪种**：
> - **单会话模式**：本文件就是接续点，每次交接覆盖重写（单值文件，同一时刻只允许一个写者）。
> - **多角色模式**：本文件只做**静态路由**，不再每次覆盖；真正的接续点在
>   `handoff/<角色>/index.md`，由各角色自己维护。
>
> 当前模式：`单会话`
>
> ⚠️ 单值文件形态下，同一工作目录同时只能有一个会话写它（组级 AGENTS.md §6「并行前提」）。
> 本文所有路径**相对项目根**（本工作区根目录）。

## 6. 规则提醒

- 四道闸（立项/规划/执行/接续）+ 调研阶段 + 结项闸：`../shared-standards/AGENTS.md`
- 多角色流水线（**可选能力**）：`../shared-standards/pipeline-and-roles.md`
- 本项目操作技能：`.dsh/skills/project-flow/SKILL.md`
- 大文件下载一律用户在主机执行（代理给下载表：网址+存储位置）
- 请示用户优先提问卡片；数字/阈值必标 [MEASURED]/[ESTIMATED]/[UNKNOWN]
- 里程碑 → ①决策回写 ②复盘 ③总结推送 → ④计划余量检查
- 每次 git 操作三问：①已设远端？②仅本地？③已推送？（模式见用户职责表）
