# 工作日志

> 每完成一个实质进展就追加一条（格式参考 `process/templates/work-log.template.md`）。
> 全路径日志（含反复修改/失败），与 construction.md（只记成功步骤）分工不同。
> 读取方式（组级 AGENTS.md §5）：**尾 N 行**——接续闸取尾 10 行；**只追加、不重写、不重排**。
> **写者**：制作人独占（多角色模式）；单会话模式下由该会话写。实现者与验收员的发现写在自己
> 单元记录里，由制作人升格（`../shared-standards/pipeline-and-roles.md`）。
