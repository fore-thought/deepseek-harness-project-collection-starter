# 真机实测记录（Measurements 模板）

> 本文件记录真机/真环境的**实测数据**，用于校准 `process/docs/assumptions.md` 中的纸面估算。
> 只有写入本文件的数字才是 [MEASURED] 级结论。

## 记录格式

```
### M-XXX｜日期｜验证的假设 ID（如 ASSUMPTION-001）

- 环境：硬件 / 软件版本 / 依赖 / 模型权重
- 命令或复现步骤：[TODO] 简述（可指向脚本路径）
- 结果：数值 + 单位（耗时、资源峰值、成本等）
- 对照：假设值 vs 实测值，偏差原因
- 备注：[MEASURED] 结论、异常、可复现性
```
