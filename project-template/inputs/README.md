# inputs（输入素材）· 本区索引

> 一、输入素材：项目获得的外部材料。本文件 = 本区内部索引，由本区自行维护。

## 子分组

- `user/`：用户提供（资源与工具）
  - `user/materials/`：资源——设定集、官方图、参考视频等，按内容再分子目录
  - `user/tools/`：工具——用户提供的软件、脚本、环境安装包等
- `ai/`：AI 调研产物
  - `ai/reports/`：调研报告（只读背景；数字均为待验证假设）
  - `ai/data/`：抓取/结构化数据（网页、JSON、语料等）

## 规则

- 新素材先归类、按类型/内容分组后入目录；只读来源不改动原文
- AI 调研数字引用前，先登记到 `../process/docs/assumptions.md`
