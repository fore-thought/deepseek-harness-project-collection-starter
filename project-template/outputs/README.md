# outputs（输出产物）· 本区索引

> 三、输出产物：项目的交付与沉淀成果，按产物类型分组。
> 本文件 = 本区内部索引，由本区自行维护。

## 产物类型

> 本模板**不预置产物类型**——类型由项目自身决定（报告、代码、图、视频、模型、数据集、
> 文稿……都是合法的）。下面只有一条通用示例，其余由项目开工时自行登记。

- `knowledge/`：知识库类产物（跨项目或跨单元可复用的内容资产）——唯一的通用示例
- `<新增类型>`：先在本 README 登记（一行：类型名 + 一句话用途），再建同名子目录

> 登记时按项目实际需要取舍，例如 `reports/`（报告）、`code/`（代码与包）、
> `media/`（图片/音频/视频）、`models/`（训练权重）、`datasets/`（数据集）。

## 规则

- 每个产物子目录自行维护索引（README 或清单）
- 跨项目复用的内容资产优先沉淀到 `knowledge/`
- 大体积产物（权重、成片、数据集）是否入库由用户在计划书里定；未定前先不入库
